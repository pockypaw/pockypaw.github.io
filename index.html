01 / 05Browser strategy game

Imperium Dawn

An empire that keeps growing — even while you sleep.

A browser-based strategy game where players build a planetary empire, run a living economy, and outthink rivals one decision at a time. Under the hood it's a real-time simulation: resources tick, queues resolve, and every player's state stays consistent.

The challenge

Game time never stops, but servers do. Progress has to be calculated fairly and precisely for every player — online or not.

What I built

A tick-based economy engine in Laravel, transactional state persistence in MySQL, and build & research queues that resolve predictably.

  • Resource production loop
  • Building & research queues
  • Player progression system
  • Consistent, persistent game state

02 / 05Japanese learning platform

EdoGo

From kana to kanji, one daily habit at a time.

A Japanese learning platform built around how memory actually works. Structured lessons, interactive practice and spaced repetition turn last-minute cramming into a daily habit learners can keep.

The challenge

Most learners don't quit because Japanese is hard — they quit because their progress feels invisible.

What I built

A React front end for fast, interactive drills, backed by a Laravel REST API that records every review and schedules the next one.

  • Hiragana, katakana & kanji drills
  • Spaced-repetition reviews
  • Interactive quizzes
  • Progress learners can actually see

03 / 05Training institute management

LPKGoEdoGo LPK

Run the entire institute from one screen.

The operations side of the EdoGo ecosystem. LPKGo replaces scattered spreadsheets and paper forms with one system for student registration, class batches, payments and instructors — so the team spends less time on admin and more time on training.

The challenge

In many training institutes, student data, schedules and payments live in separate files owned by different people. One missed update means hours of reconciliation.

What I built

A role-based Laravel + React platform on a normalized MySQL schema, with a REST API that keeps every module in sync.

  • Student enrollment records
  • Batch & class scheduling
  • Payment tracking
  • Role-based access for staff & instructors

AlFirdaus

Timeless values, with a modern digital home.

A digital home for Al-Firdaus — one place where parents, students and staff find what they need: school profile, programs, announcements and admissions information, with an admin panel the school team can run on their own.

05 / 05Point of sale for SMEs

TajirPOS

Faster checkout. Clearer numbers. A richer business.

A point-of-sale system for small and growing businesses. TajirPOS turns every transaction into data an owner can use: fast checkout at the counter, stock that updates itself, and sales reports that show what's really selling.

The challenge

For many small shops, the notebook behind the counter is the entire business intelligence system — and it can't warn you when stock is running low.

What I built

A fast, keyboard-friendly cashier interface backed by a transactional sales and inventory engine, with daily reports built in.

  • Fast checkout & receipts
  • Real-time stock tracking
  • Sales & profit reports
  • Multi-product catalog
